# MidiKeyboard
The midikeyboard starter project taken down a notch. Designed with already owned parts in mind and large forgiving pads.

![Markdown Logo](https://github.com/TheHalfBakedAsian/MidiKeyboard/blob/main/FinalMaybe.png)
the design is very wide, simply due to the pads demanding it but I am able to squeeze the height of it down a tad bit. The overall model is inspired by the starter but I took a twist to save costs and make the project more affordable on my end because I own many of the substitutes like the full cherry MX switches over low profiles and Xiao over Wave. 
This all lets me end up with a little but janky but fun design like this.
